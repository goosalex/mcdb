# mc-config module centralinfrastructure/tnsnames 

This module is used to configure the mc files in the mc config api in the path ` /centralinfrastructure/tnsnames `.

For more context, please check the central [mcfiles module README](https://github.com/Open-Systems-SASE/panta/blob/master/platforms/mc-config/mcfiles/mod/module_readme.md).

The actual configuration happens in the [mc-files-module.yaml](./mc-files-module.yaml).
